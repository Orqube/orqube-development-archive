ORQUBE 안심동행 V2.3 - 지도 중심 모바일 테스트용 전체 소스

변경
1. 안전산행·안심귀가의 원스톱 설정 최종 확인 후 GPS 세션이 시작되면 바로 이동 지도를 표시합니다.
   공유 준비 중에도 지도가 먼저 표시되고, 준비가 끝날 때까지 종료·설정 변경을 잠시 막습니다.
2. 현재/마지막 GPS 위치, 지나온 경로, 출발점, 선택한 목적지, GPS 시각·정확도를 표시합니다.
3. 이동 시간·누적 거리·공유 대상·SOS·종료를 지도와 같은 화면에서 확인합니다.
4. 안전산행: 출발점 좌표와 귀환 예정 시각. 안심귀가: 목적지까지 직선거리(도로 길찾기 거리 아님).
5. 지도를 손으로 움직이면 따라가기를 끄고, 내 위치 따라가기 버튼으로 복귀합니다.
6. 전체 동선 보기로 출발점·경로·목적지를 한 번에 확인할 수 있습니다.
7. 지도 상단 상세 메뉴로 기존 기능 화면에 돌아가도 기존 GPS 세션을 유지합니다.
   기존 화면 상단 지도 아이콘으로 다시 지도 중심 화면을 엽니다. 지도에서 뒤로 가기도 상세 화면을 엽니다.
8. 독립 위치공유도 시작 후 지도 중심 화면을 표시합니다. 기존 30분 자동 종료를 유지합니다.
9. 공유 켜짐은 상대방 수신 완료가 아닙니다. 서버 저장 응답 확인 시각과 오류를 별도로 표시합니다.
   GPS 시각이 20초 넘게 지연되면 마지막 위치로 표시합니다. 서버 저장 시각과 GPS 관측 시각을 구별하세요.
10. 산행에 저장한 오프라인 지도 이미지가 있으면 이동 지도에도 겹쳐 표시합니다.
    완전한 오프라인 지도 타일/통신두절 위치 전송은 제공하지 않습니다.
11. V2.2 초대 링크·QR 표시/스캔 및 기존 6개 언어를 포함합니다. 새 지도 문구도 6개 언어로 반영했습니다.

SOS
산행·귀가: 기존 SOS 종류 선택·확인·서버 기록 및 좌표 안내를 사용합니다.
독립 위치공유: 마지막 GPS 좌표/시각을 표시하고 기본 공유창 또는 복사로 전달합니다.
둘 다 현지 긴급기관으로 자동 신고/구조요청을 보내는 기능이 아닙니다.

Android 설치 테스트 (Windows PowerShell)
새 폴더에 이 전체 압축을 푼 뒤 해당 폴더에서:
powershell -ExecutionPolicy Bypass -File .\BUILD_TEST_APK.ps1

스크립트는 pub get → analyze → tests → debug APK 생성 순서입니다. 실패하면 다음 단계로 진행하지 않습니다.
성공하면 프로젝트 폴더에도 ORQUBE_SAFE_V2_3_TEST.apk로 복사합니다.
원본 APK 위치:
build\app\outputs\flutter-apk\app-debug.apk
이 APK를 휴대폰에 복사해 설치하거나 개발자 옵션/USB 디버깅을 켜고 flutter run으로 연결 기기를 선택하세요.
APK 빌드·설치에는 본인 PC의 Flutter/Android SDK가 필요합니다. 연결 기기는 flutter devices로 확인할 수 있습니다.
Firebase 콘솔의 Android 앱 패키지 등록이 현재 applicationId(com.orqube.orqube_safe_hiking)와 일치하는지도 확인해야 합니다. 기존 프로젝트의 인증 설정이므로 실기기 초기화 오류 시 먼저 확인하세요.
App Check가 강제 적용된 프로젝트라면 디버그 토큰을 Firebase App Check에 등록해야 할 수 있습니다.
토큰은 공개하거나 스크린샷으로 공유하지 마세요.
Play 스토어용 서명·AAB·등록은 아직 하지 않았습니다. 기존 debug 서명 설정을 유지합니다.

기기 검증
- 산행: 목적지 없이 시작/목적지 지정/이전 경로 이어하기, 귀환 예정, 출발점 표시.
- 귀가: 목적지 선택 후 바로 지도, 경로 누적/직선거리 변화/시간 증가.
- 공유 OFF: 본인 경로 표시, 공유 대상 없음. 공유 ON: 두 번째 계정에서 지도 수신 여부 별도 확인.
- 지도 드래그 → 따라가기 OFF → 내 위치 따라가기 ON, 전체 동선 보기.
- 상세 메뉴 왕복 시 기록 시간·경로가 초기화되지 않는지 확인.
- 화면 끄기·절전·통신 끊김·복구 후 GPS 시각/서버 시각/지연 표시 확인.
- SOS 취소 시 이동 유지, 종료 확인 취소 시 이동 유지, 종료 확인 시 GPS/공유 중단.
- 독립 위치공유: 시작 지도/대상 변경/30분 종료/마지막 좌표 SOS.
- 6개 언어, 휴대폰 세로·가로·큰 글꼴에서 버튼과 하단 스크롤 확인.

배포 상황
Firebase 규칙은 방금 게시한 V2.1 전체 규칙과 같습니다. 재게시가 필요하지 않습니다.
실제 웹 배포·DNS·APK 빌드·Play 공개를 이 환경에서 실행하지 않았습니다.
safe.orqubic.com은 메인과 별도 Hosting 사이트에 이 웹앱을 배포한 뒤 연결해야 합니다.
외부 초대 링크는 그 배포 후 시험하세요. 앱 내 QR 스캔·링크 붙여넣기는 먼저 시험 가능합니다.
