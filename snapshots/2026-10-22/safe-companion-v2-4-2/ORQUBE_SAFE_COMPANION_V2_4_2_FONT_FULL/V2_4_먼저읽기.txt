ORQUBE 안심동행 V2.4 — 화면과 위치 추적 세션 분리

적용 대상: 별도 Android 안심동행 앱. 공개용 웹 프로젝트용 패치가 아닙니다.
기존 V2.3 소스를 바탕으로 한 전체 소스입니다. APK는 포함하지 않습니다.

변경 내용
- GPS 구독, 경로, 서버 전송을 TripTracking 앱 세션 서비스로 이동했습니다.
- 추적 화면을 뒤로 나가거나 계정 화면을 열어도 세션을 종료하지 않습니다.
- 홈의 진행 중 카드에서 같은 시간·경로·공유 상태로 돌아옵니다.
- 동시에 두 이동을 시작하지 않고 현재 세션으로 돌아갑니다.
- 별도 30분 위치 공유도 Android 지속 알림/WakeLock을 사용합니다.
- 30분 공유는 직접 중지 또는 30분 만료 시 GPS도 종료합니다.
- 산행/귀가는 이동 종료까지 유지합니다. 공유만 중지하면 내 경로 기록은 유지합니다.
- 로그아웃·계정 변경 시 추적을 중단합니다.

PowerShell 실행 (압축 해제한 앱 폴더에서)
powershell -ExecutionPolicy Bypass -File .\BUILD_TEST_APK.ps1

생성 파일: ORQUBE_SAFE_V2_4_TEST.apk
원본 APK: build\app\outputs\flutter-apk\app-debug.apk

검증 상태
코드 점검 및 ZIP 무결성 확인만 수행했습니다.
제작 환경에 Flutter/Android SDK가 없어 flutter analyze/test/APK 빌드는 실행하지 못했습니다.
회귀 테스트 test/trip_tracking_lifecycle_test.dart를 추가했습니다. 위 스크립트가 전체 테스트를 실행하고 성공한 경우에만 APK를 빌드합니다.

실기기 확인 순서
1. 두 계정으로 가족/친구 연결 후 공유를 동의하고 산행 시작.
2. 뒤로 가기로 홈 이동. 1~2분 이동 후 보호자 지도 수신 시각과 좌표 확인.
3. 진행 중 카드로 돌아와 출발시각·경로·공유가 유지되는지 확인.
4. 화면을 잠그고 10분 이동. 보호자 화면에서 갱신 확인.
5. 카카오톡/전화 전환 후에도 갱신 확인. 절전 상태에서도 별도로 확인.
6. 산행 종료/귀가 완료 후 지속 알림이 없어지고 서버 공유가 종료되는지 확인.
7. 별도 30분 공유에서 화면 이탈 후 유지, 수동 중지 및 만료 후 GPS 종료 확인.
8. 로그아웃 및 다른 계정 전환 후 이전 계정 위치가 갱신되지 않는지 확인.

제한
이 서비스는 실행 중인 앱 프로세스가 소유합니다. 강제 종료·재부팅 후 자동 재개는 구현하지 않았습니다.
웹 브라우저의 화면 잠금/백그라운드 제한을 해결하는 수정은 아닙니다.
Android 지속 알림은 추적을 유지하도록 요청하는 장치이며 기기 절전 정책에 대한 보장은 아닙니다.
실기기 검증 전에는 안전 기능 검증 완료로 배포하지 마세요.

공개용 다운로드 교체
새 APK 검증 후 공개용 폴더에서:
powershell -ExecutionPolicy Bypass -File .\SET_COMPANION_APK.ps1 -ApkPath "새 APK의 전체 경로"
flutter build web --release
firebase deploy --only hosting
공개용 기존 스크립트의 표시 버전은 V2.3일 수 있으므로 별도 확인해야 합니다.
