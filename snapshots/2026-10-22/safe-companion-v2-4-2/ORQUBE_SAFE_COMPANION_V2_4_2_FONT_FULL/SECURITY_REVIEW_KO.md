# 소스 보안 점검 결과 (2026-10-11)

확인한 사항: Firebase Auth 사용, 앱 자체 비밀번호 저장 코드 없음, 웹 LOCAL 로그인 유지 설정, 탈퇴 전 비밀번호 재인증, 계정 변경 시 GPS 스트림·타이머·화면 정보 정리, 본인 UID 기반 서버 접근 제한 예시, 본인 기록 삭제 흐름.

보완: 원본 users 보호자 설정 쓰기 권한 누락과 SOS 삭제 권한 누락 수정. 보호자 자동 전달·119 자동 신고로 오해할 수 있는 안내 수정. 공유 종료 시 오프라인 서버 반영 지연 안내. 첫 실행 위치·개인정보 설명 추가.

미확인: Flutter 정적 분석/컴파일, APK 빌드/서명, 실기기 권한/백그라운드, 운영 서버 규칙/데이터, App Check enforcement, 백신 및 침투 테스트. 따라서 외부 보안 검증 완료 표시는 없음.

운영 제한: Firebase 공통 계정 탈퇴는 다른 ORQUBE 앱 로그인에도 영향. 삭제는 안전산행 관련 문서와 보호자 필드 대상이며 다른 앱 데이터/서버 백업/외부 메시지 삭제는 포함하지 않음. 기록 삭제는 여러 단계이므로 통신 실패 시 일부만 삭제될 수 있으며 재시도 필요. Firestore 로컬 캐시는 로그아웃으로 완전 소거된다고 보장하지 않음. 저장 지도 삭제 저장소의 I/O 실패는 기존 구현상 별도 검증되지 않음.

참고: https://firebase.google.com/docs/auth/flutter/manage-users 및 https://firebase.google.com/docs/auth/flutter/start
