ORQUBE 안심동행 V2.2 전체 개발용 소스 (APK 아님)

추가된 기능
- 사람·모임 → 사람 추가: 기본 공유창, 초대 링크 복사, 내 QR 표시, 상대 QR 카메라 스캔.
- WhatsApp/LINE/문자/이메일/카카오톡 등은 기기의 기본 공유창에서 설치 앱 중 선택.
  웹 브라우저나 운영체제에 따라 공유 대상 목록은 다릅니다. 공유가 지원되지 않으면 링크 복사를 사용하세요.
- 받은 링크 붙여넣기와 기존 연결 ID 직접 입력도 지원.
- 외부 초대 링크는 safe.orqubic.com을 사용하며, 앱의 카메라로 QR을 스캔하면 도메인 배포 전에도
  연결 정보를 읽을 수 있습니다. 외부 링크를 직접 여는 기능은 반드시 해당 도메인에 이 웹앱 배포 후 시험하세요.
- 링크 확인은 로그인 전에도 가능. 연결 요청/승인에는 로그인과 이메일 인증 필요.
- 홈에서 받은 초대를 표시하고 로그인 중에도 보관합니다. 개인정보 안내 화면은 그대로 유지합니다.
- 링크를 열거나 QR을 읽는 것만으로 연결/위치 공유가 시작되지 않습니다.

승인 흐름
A가 자신의 QR 또는 링크를 B에게 보냅니다.
B가 확인하고 A를 알아볼 이름·관계를 입력한 뒤 연결 요청을 보냅니다.
A는 사람·모임의 받은 초대에서 승인합니다.
B가 이미 A에게서 받은 대기 초대가 있는 경우에는 확인 버튼으로 그 요청을 수락합니다.
연결 후 산행/귀가/위치공유 시작 시 공유 대상을 별도로 선택합니다.
링크는 계정 ID 안내용이며 위치 접근권이나 일회용 비밀 토큰이 아닙니다.
기존의 공유 중지/이름·관계 변경/양쪽 연결 해제를 유지합니다.

도메인과 APK
- 아직 Firebase Hosting/DNS를 배포하거나 변경하지 않았습니다.
- 메인 사이트를 덮어쓰지 말고, 별도 Hosting 사이트에 이 웹앱을 배포한 뒤 safe.orqubic.com을 연결하세요.
- 웹 로그인 허용 도메인/Firebase App Check 도메인 설정도 운영 환경에 맞게 확인해야 합니다.
- 설치된 앱에서 열기 버튼은 Android/iOS의 orqubesafe 커스텀 스킴을 사용합니다.
  HTTPS 링크가 바로 APK를 여는 검증된 Android App Link는 아직 구성하지 않았습니다.
  이를 위해서는 최종 서명 인증서와 전용 도메인의 assetlinks.json 설정이 별도로 필요합니다.
- 카메라 접근은 QR 스캔 화면에서 요청합니다. 거부 시 뒤로 가서 링크를 붙여넣을 수 있습니다.
- 이미 게시하신 ORQUBE_FIRESTORE_V2_1_FULL.txt와 같은 규칙을 사용합니다. 규칙 재게시 불필요.

실행 (새 폴더에서)
flutter pub get
flutter analyze --no-fatal-infos
flutter test
flutter run -d chrome --web-port=7355
Android 테스트 APK: 기존 BUILD_TEST_APK.ps1을 실행합니다.
카메라 웹 스캔은 HTTPS 또는 localhost와 카메라 장치가 필요합니다.

검증 범위
Dart 문법 파싱, Android XML, 새 문구 33개의 6개 언어 항목, 기존 규칙 동일 여부를 정적으로 확인했습니다.
Flutter/Dart/Android SDK가 없는 제작 환경이므로 flutter analyze/test/build 및 실기기 QR/공유/로그인 검증은 실행하지 못했습니다.
추가 패키지: qr_flutter 4.1.0, mobile_scanner 7.4.2, app_links 6.4.1.
APK 릴리스 서명/Play 등록/공개 배포는 수행하지 않았습니다. 기존 debug 서명 설정을 그대로 유지합니다.

실기기 확인 순서
1) 두 계정 로그인·이메일 인증 → A의 QR을 B가 스캔 → 확인 전 요청이 생기지 않는지 확인.
2) B 요청 → A 받은 초대 승인 → 양쪽 연결 목록 → 공유 시작 후 지도 수신 확인.
3) B가 다른 QR/외부 URL을 읽으면 거절되는지, 본인 QR은 연결되지 않는지 확인.
4) 카메라 거부 시 뒤로 가기·링크 붙여넣기, 스캔 후 카메라 종료 확인.
5) 도메인 배포 후 로그인 전/후 링크 열기, 초대 닫기, 설치 앱 열기 확인.
6) 연결 해제 후 상대의 새 위치·수색자료 서버 조회가 차단되는지 확인.

이 버전의 범위는 초대 링크와 QR입니다. 원스톱 설정 종료 후 지도 중심 화면 자동 전환 개선은 아직 별도 작업입니다.
