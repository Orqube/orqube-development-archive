ORQUBE Safe Companion V1.9.1 전체 소스

V1.8.1 실시간 지도와 V1.9 수색 보완 기능을 포함한 전체 소스입니다.
APK가 아닌 Flutter 개발 소스이며 새 폴더에 압축을 풀어 실행하세요.

1. 상세 설명서
안전산행 화면의 '안전산행 상세 안내' 또는 통합 사용설명서 상단 버튼으로 엽니다.
밝은 배경의 11개 펼침 항목에 다음 내용을 자세히 설명합니다.
안심귀가와 안전산행의 차이 / 출발 전 설정과 보호자 승인 / 기기 우선 경로 저장 /
통신두절과 저장 지도 / 재전송 / 실시간 지도와 마지막 기록의 차이 /
별도 동의와 24시간 조회 / 기록 이어가기 / GeoJSON 내보내기 /
공유 종료·접근 해제·삭제 / 보호자 확인 순서와 한계.
마지막 기록은 현재 위치가 아니며 자동 구조 접수가 아니라는 점을 구분했습니다.
기기 10,000점과 서버 4,000점, 실시간 최근 500점의 차이도 안내합니다.

2. 6개국어 공통 수정
한국어/영어/일본어/중국어/프랑스어/포르투갈어에 같은 안내 구조를 사용합니다.
긴 문장에서 단어만 바꾸던 부분 치환을 제거하고 완성된 문장 번역을 사용합니다.
상태 문구의 모드·보호자 이름·시간은 이름 붙인 자리표시자로 넣습니다.
사용자가 입력한 이름·이메일·ID·주소와 외부 서버 오류 원문은 임의 번역하지 않습니다.
사진에 나온 로그인 상단·산 그림 아래 부제·계정 하단 안내·두 대시보드 시작 순서·
진행/대기·서버 활성/비활성·보호자 자동 알림 안내·개인 기록 설명을 보완했습니다.
로그인 입력 힌트·입력 검증·비밀번호 표시 버튼과 수색 화면 안내도 점검했습니다.
신규 11개 설명서 항목의 제목과 본문을 모두 6개 언어로 제공합니다.

3. Firebase
이번 V1.9.1은 V1.9와 같은 규칙을 사용합니다. V1.9 추가 규칙을 이미 게시했다면 재게시할 필요 없습니다.
아직 적용하지 않았다면 SEARCH_RULES_V19.txt를 기존 규칙 안에 추가하고 게시해야 수색자료 서버 기능을 사용할 수 있습니다.
기존 V1.7 보호자 규칙과 인증 함수도 필요합니다. 서버에는 대신 게시하지 않았습니다.
24시간은 보호자 읽기 만료입니다. 물리적 자동 삭제를 원하면 Firestore TTL 설정이 별도로 필요합니다.

flutter pub get
flutter analyze --no-fatal-infos

flutter run -d chrome --web-port=7354
테스트 APK: powershell -ExecutionPolicy Bypass -File .\BUILD_TEST_APK.ps1

5. 언어 점검 순서
언어 버튼에서 6개 언어를 하나씩 선택합니다.
첫 실행 안내와 동의 / 로그인 전후 / 안전산행 / 안심귀가 / 보호자 연결 /
실시간 지도 / 수색자료 / 통합 설명서 / 안전산행 상세 안내를 확인하세요.
상태 대기·진행, 공유 끔·켬, 비밀번호 오류·이메일 인증, 긴 설명 펼침도 확인하세요.
한국어로 입력한 보호자 이름·주소가 그대로 남는 것은 정상입니다.
모바일 390px/데스크톱에서 긴 프랑스어·포르투갈어 문장 줄바꿈을 확인하세요.

6. 실제 검증 범위
문법 파서, 상대 import 경로, 번역 값·자리표시자 정적 검사, ZIP 무결성을 검사합니다.
신규 테스트는 전체 번역 행의 5개 대상 언어·한국어 잔류·자리표시자 일치,
사진에 나온 문장 전체 번역, 6개 언어 가이드 전환을 검사하도록 작성했습니다.
Flutter/Dart/Android SDK가 없어 flutter analyze/flutter test/APK 빌드 및 실제 화면 검증은 실행하지 못했습니다.
정적 번역 검사는 실제 모든 앱 상태의 완전 번역이나 번역 품질의 원어민 검수를 보증하지 않습니다.
전체 앱에 남을 수 있는 드문 서버 오류·외부 데이터·지도 제공자 텍스트는 별도 실기기 확인 대상입니다.
