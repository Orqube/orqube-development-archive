ORQUBE 안심동행 V1.8.1 오류수정 통합 전체 소스 — 실시간 이동 지도 개선

변경
보호자 지도: Firestore 변경 수신, 수신된 좌표 사이 약 0.9초 마커 애니메이션.
움직이지 않은 좌표를 임의로 예측하지 않습니다. 2km 이상 좌표 점프는 애니메이션 없이 표시합니다.
상대방 따라가기/전체 경로 보기. 갱신 때마다 지도를 새로 만들던 동작 제거.
지도에 최근 경로 최대 500지점 표시. 녹색 시작점과 사람 모양 현재 위치.
전송 목표: 2m 이상 이동 시 5초, 정지 중 15초. 실제 간격은 GPS/통신/기기 절전에 따라 늘어납니다.
20초 이상 서버 갱신이 없으면 지연 표시. 캐시 데이터는 저장 위치로 표시.
2분 만료 또는 공유 종료 시 지도 숨김. 서버 접근 거부 시 기존 데이터 표시를 지웁니다.

휴대폰
Android 위치 기록 시작 시 geolocator foreground notification 설정과 WakeLock을 사용하도록 추가했습니다.
화면을 켠 상태에서 앱을 열고 이동 시작/위치 공유에 동의한 후 사용하세요.
이 설정만으로 모든 제조사 절전/화면 꺼짐/강제 종료에서 연속 전송을 보장하지 않습니다.
이동 페이지를 떠나면 공유 종료를 시도합니다. 웹 백그라운드 탭은 갱신이 중단될 수 있습니다.
배터리 소비와 Firestore 읽기/쓰기 사용량은 기존 15초 방식보다 증가할 수 있습니다.

서버
필드/조회 권한은 V1.7과 동일합니다. V1.7 보호자 규칙이 이미 게시되어 있다면 이번 기능만으로 재배포할 필요 없습니다.
원래 제공한 엄격한 규칙만 사용 중이라면 V1.7의 승인/해제 보완을 확인하세요.

실행
이전 Flutter 실행 Ctrl+C 후 새 폴더에서:
flutter pub get
flutter analyze --no-fatal-infos
flutter test
flutter run -d chrome --web-port=7354
테스트 APK: powershell -ExecutionPolicy Bypass -File .\BUILD_TEST_APK.ps1
파일: build\app\outputs\flutter-apk\app-debug.apk
Debug APK의 App Check 디버그 토큰은 Firebase 콘솔에서 등록해야 합니다. 토큰은 공개하지 마세요.

두 휴대폰 검증
A 공유자/B 보호자 각자 이메일 인증 로그인 → B 요청 → A 승인 → A 이동 시작/공유 동의.
B 위치 확인 → A 실제 이동 → B 지도 마커/파란선/수신시간 확인.
따라가기/전체 경로 → A 통신 끊기 → B 20초 지연, 2분 만료 확인.
A 공유 종료 및 B 권한 해제 → B 데이터가 숨겨지는지 확인.
안전산행/안심귀가 두 모드 각각 테스트. 화면 꺼짐 5~10분/절전 켜기/앱 강제 종료도 별도 확인.

검증 한계
Flutter/Dart/Android SDK가 없어 실제 flutter analyze/flutter test/APK 빌드는 실행하지 못했습니다.
수신 지연 상태/좌표 보간/날짜변경선 처리 테스트 코드를 추가했습니다. 기본 소스·ZIP 정적 검사만 수행했습니다.
정식 출시 승인본이나 보험사 수준 실서비스 동작 검증 완료본은 아닙니다.
다국어 지도 상세 안내 일부는 이전 버전과 같이 미완성입니다.

V1.8.1 추가 수정
V1.7.1의 색상 상수 선언과 방위 names 선언 수정 포함.
손으로 지도를 이동/확대하면 자동 따라가기를 멈춥니다. 따라가기 버튼으로 다시 켭니다.
출발점으로 돌아온 순환 경로도 전체 경로 보기에 포함됩니다.
기존 폴더에 덮어쓰지 말고 이 압축본을 새 폴더에 풀어 실행하세요.
실시간 지도 개선을 포함한 전체 소스이며 패치 파일이나 APK 파일이 아닙니다.
