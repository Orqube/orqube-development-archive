ORQUBE 안전산행 — LOGIN UI V2 (2026-10-12)

이 파일은 로그인 화면을 다시 설계한 전체 앱 압축본입니다.
기존 폴더에 덮어쓰지 말고, 새 폴더 C:\orqube\SAFE_HIKING_LOGIN_V2 에 압축을 풀어주세요.
pubspec.yaml과 RUN_LOGIN_V2.ps1이 있는 폴더에서 실행합니다.

1. 이전 flutter run PowerShell 창에서 Ctrl+C를 눌러 실행을 종료하세요.
2. 이전 앱이 열린 Chrome 탭을 닫으세요.
3. 새 압축본의 앱 폴더를 열고 탐색기 주소창에 powershell을 입력합니다.
4. 아래 명령을 실행하세요.

powershell -ExecutionPolicy Bypass -File .\RUN_LOGIN_V2.ps1

스크립트 대신 한 줄씩 실행하려면:
flutter pub get
flutter run -d chrome --web-port=7352

7352 포트가 사용 중이라면 이전 실행을 종료하거나 7353 등 다른 포트로 바꿔주세요.

새 화면 확인 기준:
- 녹색 산 배경과 "마음 편한 산행, 여기서 시작하세요."
- 흰색 입력 카드와 "다시 만나 반갑습니다"
- 녹색 배경·흰색 글자의 "로그인" 버튼
- 로그인 / 회원가입 탭
- 화면 아래 "ORQUBE SAFE HIKING · LOGIN UI V2"
- 이미 로그인되어 있으면 로그인 입력 대신 이메일·인증 상태·로그아웃이 보입니다.

LOGIN UI V2 표시가 없다면 이 압축본 화면이 아닙니다.
이전 실행 폴더, Chrome 주소, 기존 실행 프로세스를 확인해주세요.

변경 사항:
- 계정 페이지를 독립된 밝은 테마로 구성해 지도 화면의 어두운 테마와 분리.
- 로그인 글자와 입력값·라벨·버튼 색을 명시적으로 지정.
- 넓은 화면은 산행 소개 / 입력 카드 2열, 좁은 화면은 세로 배치.
- 회원가입 동의는 회원가입 탭에만 표시.
- 이메일 형식 확인, 비밀번호 보기/숨기기, 처리 중 중복 클릭 방지.
- 산행 화면으로 복귀, 이메일 인증, 비밀번호 재설정, 기존 기록 삭제·탈퇴 기능 유지.
- 카카오·문자 공유 등 기존 안전산행 소스 유지.
- 이전 ZIP의 ios/Flutter/ephemeral 및 백업 등 임시 생성 파일을 압축본에서 제외.

검증 범위:
