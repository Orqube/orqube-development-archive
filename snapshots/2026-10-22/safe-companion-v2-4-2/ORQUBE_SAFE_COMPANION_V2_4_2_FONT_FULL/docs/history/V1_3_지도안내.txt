V1.3 전체 소스 — 보호자 화면 카드형 밝은 테마/지도 경로 개선
지도는 위치 조회 성공 시 표시됩니다. 초록 시작점/파란 최근 이동선/빨간 현재 위치.
경로 전체가 보이도록 갱신 시 지도 범위를 맞춥니다. 위치 공유 직후에는 점 하나만 보이며 이동 후 경로가 생깁니다. 최근 최대 500개 지점입니다.
permission-denied는 화면 문제가 아니라 Firebase 권한 거부입니다. 인증 완료 계정에서도 서버 보호자 규칙/App Check 확인이 필요합니다.
Firebase 현재 규칙 전체를 제공해주시면 기존 서버 규칙과 병합할 수 있습니다. 이 소스는 서버를 자동 변경하지 않습니다.
실행: flutter pub get → flutter analyze → flutter run -d chrome --web-port=7353
Flutter 실행/화면 렌더링은 이 제작 환경에서 검증하지 못했습니다.
