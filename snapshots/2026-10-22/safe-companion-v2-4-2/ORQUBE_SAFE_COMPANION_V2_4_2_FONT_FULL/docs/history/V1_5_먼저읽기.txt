V1.5 전체 소스 — 첫 화면/설명서 밝은 카드형 디자인, 로그인 유지 점검

첫 화면과 통합 설명서: 밝은 회녹색 배경, 흰색 카드, 짙은 녹색 글자.
지도 화면의 기존 어두운 테마는 유지합니다. 보호자 화면은 밝은 테마 유지.

이메일 인증은 Firebase 계정에 저장됩니다. 로그아웃해도 인증 완료 자체가 취소되지 않습니다.
같은 브라우저/주소에서 로그인은 LOCAL 영속성으로 유지하며 시작 시 인증 상태·토큰 갱신을 시도합니다.
네트워크 오류만으로 강제 로그아웃하지 않습니다.
사용자가 로그아웃하거나 계정 삭제/비활성화, 세션 취소, 브라우저 데이터 삭제 등이 있으면 재로그인이 필요할 수 있습니다.
localhost:7353과 localhost:7354는 다른 사이트 저장소입니다. 포트 변경 시 로그인 유지가 이어지지 않을 수 있습니다.
기존 7354에서 로그인했다면 이후에도 7354를 계속 사용하세요. 시크릿 창은 이용하지 마세요.

실행: 이전 Flutter 실행 창에서 Ctrl+C 종료 후 새 V1.5 폴더에서:
flutter pub get
flutter analyze
flutter run -d chrome --web-port=7354
7354 사용 중이면 이전 실행을 종료하고 같은 포트로 다시 실행하세요.

보호자 permission-denied는 별도 서버 규칙 확인이 필요하며 이번 화면 수정으로 해결됐다고 볼 수 없습니다.
제작 환경에서 기본 정적 검사와 ZIP 검사는 수행했으나 Flutter 실행/화면 렌더링/기기 빌드는 수행하지 못했습니다.
