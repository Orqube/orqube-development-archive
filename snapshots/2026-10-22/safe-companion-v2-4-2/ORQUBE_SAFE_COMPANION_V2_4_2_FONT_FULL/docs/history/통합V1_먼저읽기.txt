ORQUBE 안심동행 통합 V1 — 2026-10-15

로그인 V2 디자인 유지. 첫 안내 완료 후 안전산행/안심귀가/보호자 연결 메뉴 추가.
기존 앱 식별자와 Firebase 설정 유지. 기존 프로젝트를 신규 Firebase 프로젝트로 바꾸지 않습니다.

[실행]
기존 flutter run을 Ctrl+C로 종료하고 새 폴더에 압축을 풉니다.
pubspec.yaml이 있는 폴더에서 PowerShell:
flutter pub get
flutter analyze
flutter run -d chrome --web-port=7353
또는 powershell -ExecutionPolicy Bypass -File .\RUN_COMPANION.ps1
Flutter analyze 오류가 있으면 배포하지 말고 결과를 확인하세요.
Android: flutter build apk --release
Play 출시: 업로드 키/릴리스 서명 설정 후 flutter build appbundle --release
이 압축본은 소스이며 설치 APK/AAB가 아닙니다.

[서버 규칙: 필수]
기존 오르큐브 Firestore 규칙을 통째로 덮어쓰지 마세요.
firestore.rules.example의 safety_requests, safety_shares, safe_home_sessions 블록을 기존 규칙에 합쳐 검토합니다.
동일 경로의 기존 허용 규칙이 있다면 중복/상위 와일드카드 허용도 함께 점검합니다.
위치 데이터 전체 공개 규칙(allow read: if true)은 사용하지 마세요.
서버 규칙을 배포하지 않으면 보호자 연결은 작동하지 않습니다.
전용 테스트 프로젝트에서만 예제 전체 규칙을 사용할 수 있습니다:
firebase deploy --only firestore:rules --config firebase.companion.example.json --project 실제_테스트_프로젝트_ID
Firebase 로그인 제공자, 이메일 인증, App Check 설정도 기존 안내대로 확인하세요.

[보호자 이용: 양쪽 로그인/이메일 인증]
1. 산행자/귀가자가 '보호자 연결'에서 자기 연결 ID를 지정 보호자에게 전달합니다.
2. 보호자는 로그인 후 그 ID를 입력하고 '상대방에게 연결 요청'을 누릅니다.
3. 산행자는 들어온 요청 ID를 직접 확인하고 승인합니다.
4. 산행자는 이동 화면에서 산행/귀가 시작 후 위치 공유를 동의하고 시작합니다.
5. 보호자는 같은 ID로 '승인 후 상대 위치 확인'을 누릅니다.
지도에 현재 좌표와 최근 경로 최대 500개 지점, 마지막 수신 시간이 표시됩니다.
약 15초 갱신. 서버 갱신이 2분 이상 없으면 조회 만료.
공유 중지/이동 종료 또는 보호자 접근 해제를 통해 조회를 차단합니다.
승인 보호자 최대 10명. 연결 ID만 안다고 위치를 읽을 수 없습니다.
전화번호는 기존 문자 공유에만 사용하며 번호 검색/자동 SMS 인증은 추가하지 않았습니다.
문자/카카오톡 공유는 사용자가 직접 발송하는 현재 좌표 메시지입니다.
앱 설치 없는 보호자 웹 전용 링크는 아직 제공하지 않습니다.

[한계와 기기 테스트]
Flutter SDK가 없는 제작 환경에서 소스 연결/정적 검사/ZIP 무결성을 점검했습니다.
flutter analyze, 실행 화면, APK 빌드, Firebase 서버 규칙 테스트는 수행하지 못했습니다.
첫 버전은 앱/웹 실행 중 공유입니다. 화면 꺼짐/절전/강제 종료 후 연속 공유는 보장하지 않습니다.
자동 지연 알림/자동 SOS/112·119 자동 신고, 백그라운드 서버 감시는 구현하지 않았습니다.
통신이 끊기면 상대가 보는 위치는 최신이 아닐 수 있습니다. 마지막 수신 시간을 확인하세요.
공유 종료가 서버에 전달되기 전에는 이전 위치가 최대 2분간 조회될 수 있습니다.
앱을 다시 열면 위치 공유를 다시 시작하세요. 지도 타일은 인터넷이 필요합니다.
양쪽 계정으로 승인 전 거부, 승인 후 조회, 이동 갱신, 종료 후 거부, 접근 해제, 절전/통신 단절을 테스트하세요.

[광고]
광고는 안전 기능 검증 후 AdMob으로 연결합니다. 이번 버전에는 광고 SDK/실제 광고를 넣지 않았습니다.
AdMob 앱 ID와 배너 광고 단위 ID, app-ads.txt, 동의 처리/개인정보 안내가 필요합니다.
운영 광고 ID를 임의로 만들지 않았습니다. 지도 조작/SOS/이동 진행 화면에는 전면 광고를 넣지 않는 구성을 권합니다.

[개인정보]
보호자 요청 ID/이름, 승인된 UID 목록, 공유 중 위치와 최근 경로가 Firebase에 저장됩니다.
공유 종료 시 safety_shares의 경로를 비우지만 기존 개인 산행/귀가 기록은 계정에서 삭제합니다.
계정 화면의 기록 삭제는 내 safety_shares와 받은 요청도 삭제합니다.
다른 계정에 보낸 미승인 요청은 자동 정리되지 않으므로 이름은 기본 '보호자'로 최소화했습니다.
플레이 공개 전 실제 처리방침과 삭제 요청 웹페이지, 위치 고지/권한 및 보존 정책을 확정하세요.
