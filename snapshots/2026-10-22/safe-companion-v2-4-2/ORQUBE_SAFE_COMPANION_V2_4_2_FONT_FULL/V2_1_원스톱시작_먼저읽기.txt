ORQUBE 안심동행 V2.1 전체 소스 — 단계별 원스톱 시작

V2.0의 가족·친구/개인 모임/초대·수락/개별 공유·해제와 V1.9.1의 수색 보완 기능을 포함합니다.
기존 첫 화면 메뉴와 지도 화면의 개별 버튼은 유지합니다.
안전산행·안심귀가 시작 버튼을 누르면 이제 단계별 준비 화면을 엽니다. 모바일뿐 아니라 PC에서도 같은 흐름을 제공합니다.

6단계
1. 이용 안내: 설명 확인, 이해 체크. 저장된 산행이 있으면 이어가기/새 기록 선택.
2. 동의 확인: 개인정보 처리 안내와 이번 이동의 위치 이용 동의를 각각 읽고 선택.
3. 내 위치: 직접 버튼을 눌러 위치 권한 요청 및 GPS 좌표·정확도 확인.
4. 목적지·계획: 주소/장소 검색 또는 지도 터치로 지정. 산행은 목적지 없이 경로만 기록도 선택 가능.
   안전산행의 귀환 예정 날짜·시간을 변경할 수 있습니다. 안심귀가는 목적지가 필요합니다.
5. 공유 대상: 공유 없이 내 기록만 시작하거나 가족·친구에게 공유 선택.
   사람별 체크와 모임 묶음 선택, 사람 추가/초대 관리로 이동 가능합니다.
   안전산행 마지막 기록 조회는 상대별로 별도 체크합니다.
6. 최종 확인: 위치·목적지·귀환 예정·공유 대상·기록 이어가기 여부를 검토하고 시작.

사용성
밝은 배경, 본문 17px, 넓은 줄간격, 가운데 최대 폭 720px, 하단 고정 이전/다음 버튼.
단계 번호와 진행 막대, 각 단계 조건 충족 전 다음 버튼 비활성.
이전으로 돌아가도 준비 화면 안의 입력을 유지합니다.
최종 확인 전 GPS 추적/이동 기록/위치 공유는 시작하지 않습니다.
다만 직접 허용한 기기 위치 권한 및 별도로 보낸 초대/수락은 취소로 되돌리지 않습니다.
화면 취소 시 기존 지도 메뉴로 돌아옵니다. GPS 한 번 확인은 위치 이용 동의 이후에만 직접 요청합니다.
공유 대상 선택 팝업은 여기서는 임시 선택이며 최종 확인 후에만 서버의 공유 대상을 적용합니다.
완료 후 같은 동의/대상 선택 팝업을 다시 띄우지 않으며 외부 내비게이션 앱도 자동으로 열지 않습니다.
기존 내비게이션 메뉴는 그대로 사용할 수 있습니다.

기록/공유
공유하지 않는 개인 산행은 보호자 연결이나 대상 선택 없이 시작할 수 있습니다.
공유하려면 상대 수락·이메일 인증과 V2.0 보안 규칙이 필요합니다.
준비 화면에서 새 가족/친구를 추가했다면 상대가 수락한 뒤 다시 공유 대상 선택을 누르세요.
공유 설정 실패 시 이동 기록이 시작됐는지 구분해 안내합니다. 기존 위치 공유 메뉴에서 재시도할 수 있습니다.
확인한 GPS가 5분 이상 지났으면 위치 단계로 돌아가 재확인하도록 합니다.
산행 새 기록 시작은 이전 기기 기록을 교체하므로 첫 단계와 최종 화면에서 선택을 확인하세요.
이 기기의 마지막 시작 동의는 trip_consent_v1_UID에 버전·시각·모드·공유 여부로 저장합니다.
새 동의가 이전 시작 기록을 교체하며 법적 서명 증빙이나 전체 동의 이력 시스템은 아닙니다.
수색자료 조회 24시간, 기록 저장, 오프라인·앱 종료 한계는 기존 상세 안내와 동일합니다.

6개 언어
새 안내·동의·단계 제목·오류 문구를 한국어/영어/일본어/중국어/프랑스어/포르투갈어로 추가했습니다.
사용자 입력 이름/주소/ID와 좌표는 번역하지 않습니다.

서버 규칙
V2.0과 동일합니다. V2.0 규칙을 적용했다면 이번에는 다시 갱신하지 않아도 됩니다.
아직 V1.x 규칙이면 V2_0_내사람_공유설정_먼저읽기.txt의 교체 절차가 필요합니다.
실제 서버 게시와 도메인 DNS 연결은 이 파일 작성으로 진행되지 않습니다.

검증 순서
390px 모바일과 PC에서 시작 도우미를 엽니다. 6개 언어 각각 확인하세요.
안내 이해 체크 전 다음 차단, 두 동의 중 하나만 체크하면 다음 차단 확인.
GPS 버튼 누르기 전 자동 권한 요청이 없는지 확인. 거절/위치 꺼짐 후 다시 확인.
주소 검색 실패 시 지도 직접 선택과 산행 경로만 기록 선택을 확인.
귀가 목적지 미선택, 산행 과거 귀환시간, 공유 켬+대상 없음은 다음 차단 확인.
이전 단계 입력 유지, 마지막 확인 전 취소 후 추적/공유 미시작 확인.
개인 기록만 시작 / 가족·친구 공유 시작 / 사람별 수색자료 허용을 각각 확인.
가족 초대/상대 수락 후 준비 단계로 돌아와 선택 가능한지 확인.
저장된 산행 이어가기와 새 기록의 차이, 위치 확인 후 5분 경과 재확인 확인.
최종 확인 후 중복 동의 팝업이나 외부 내비게이션 자동 실행이 없는지 확인.
두 계정으로 실제 위치 수신/선택 안 한 사람 접근 거부/공유 중지 확인.
