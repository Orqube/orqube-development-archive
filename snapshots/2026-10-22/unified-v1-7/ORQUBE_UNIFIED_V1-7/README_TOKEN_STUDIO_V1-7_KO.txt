ORQUBE 통합본 V1-7 · AI TOKEN STUDIO

기준 원본
정상 ZIP 검사에 통과한 V1-5 전체 파일을 기준으로 작성했습니다.
손상된 V1-6에서도 각 파일의 길이·CRC 검사를 통과한 공통 로그인 관련 17개 파일은 복구하여 병합했습니다.
V1-6의 손상된 이미지 파일로 V1-5의 정상 이미지를 덮어쓰지 않았습니다.

수정 내용
1. 기존 첫 화면의 검색형 토큰 아이디어 입력을 유지합니다.
2. 토큰 생성 센터에도 검색형 아이디어 입력·내 토큰·지갑 생성·스테이킹 버튼을 추가했습니다.
3. 이름·심볼·설명·Vision·Utility 자동 초안은 기존 AI 서버를 사용합니다.
   Firestore의 AI 설정 문서 읽기가 거부되어도 기본 인증 API 호출을 시도하도록 수정했습니다.
   서버 호출 실패 시 로컬 초안이라는 기존 안내를 표시합니다. 로컬 초안을 외부 AI 결과로 표시하지 않습니다.
4. 발행량은 자동으로 채우지 않습니다. 사용자가 직접 입력합니다.
5. 원·육각형·마름모와 4가지 색상의 무료 도형 로고를 제공합니다.
   로고 설정은 launch_projects의 logoSpec에 저장하며, 프로젝트 화면과 홈 토큰 카드에도 표시합니다.
6. 초안 적용 전 검토 창을 제공합니다. 돌아가서 수정할 수 있습니다.
   이 단계는 초안 저장이며 배포·송금·결제를 자동 실행하지 않습니다.
7. KAIA 지갑주소 생성 화면을 추가했습니다.
   기기에서 보안 난수와 web3dart로 EVM 주소·암호화 V3 JSON을 생성합니다.
   암호화 파일 저장 → 같은 파일로 복구 확인 → 공개 주소 등록 순서입니다.
   개인키·비밀번호·암호화 백업은 서버에 저장하지 않습니다.
   기존 공개 주소가 있으면 교체 전 사용자 확인을 받습니다. 자산은 자동 이동하지 않습니다.
   배포·전송 서명은 암호화 백업 가져오기를 지원하는 지갑과 기존 연결 기능을 사용합니다.
   이 화면은 12단어 복구구문을 생성하는 방식이 아닙니다.
8. 스테이킹은 실제 등록된 https://staking.orqubic.com 링크로 연결합니다.
9. 기존 웹·앱 초안은 같은 Firebase 계정의 '내 토큰'에서 조회합니다.
10. 기존 Kairos 배포·전송과 결제·소스검증 코드는 유지했습니다.
    공개 목록과 결제정책 조회 서버 패치 두 함수를 통합했습니다.

중요한 적용 상태
이 ZIP은 소스 수정본입니다. Firebase 또는 별도 Meme Studio 사이트에 이번 변경을 배포하지 않았습니다.
이 원본의 기존 결제 설정은 Kaia 테스트 결제 모드 10 KAIA가 켜져 있습니다.
기존 설정과 요금은 이번 수정에서 변경하지 않았습니다. 정상 운영 요금 전환을 했다는 의미가 아닙니다.
별도 Meme Studio 사이트의 3유형 생성 화면을 새로 구현·검증한 결과물은 이 ZIP에 포함되지 않습니다.
기존 테스트넷 엔진을 이용하는 웹 브라우저의 지갑 연결과 APK의 지원 범위는 서로 다릅니다.
APK에서 새 배포·송금 서명 어댑터를 구현한 것은 아닙니다.

검증 결과
- 원본 ZIP: 605개 항목 압축·CRC 검사 통과.
- AI 서버 JavaScript 구문 검사 통과.
- 신규 공개 목록/권한/정책 테스트 4개 통과.
- 전체 AI 서버 테스트: 75개 중 66개 통과, 9개 실패.
- 원본을 별도 폴더에서 같은 방법으로 검사: 71개 중 62개 통과, 동일한 9개 실패.
  원본의 토론 권한·마케팅 승인 관련 실패는 이번 작업 범위에서 수정하지 않았습니다.
- 이 환경에 Flutter SDK가 없어 Flutter 빌드, Dart 정적 분석, 지갑 암호화 테스트,
  모바일 화면, 실제 지갑 생성/백업 복구, 테스트넷 배포·송금·결제는 미실행입니다.
  추가한 test/generated_kaia_wallet_test.dart는 설치된 Flutter 환경에서 실행해야 합니다.

PowerShell 실행
압축을 푼 프로젝트 최상위 폴더에서:
  powershell -ExecutionPolicy Bypass -File .\BUILD_TOKEN_STUDIO.ps1

스크립트는 패키지 설치, 지갑 테스트, 웹 빌드까지만 실행하며 배포하지 않습니다.
성공 후 화면 확인:
  flutter run -d chrome

화면·지갑 백업 확인 후 웹 배포:
  firebase deploy --only hosting --project orqube-576e7

공개 목록/정책 조회 두 함수만 배포:
  firebase deploy --only "functions:ai:getPublicLaunchTokens,functions:ai:getMobileStudioPolicy" --project orqube-576e7

기존 AI 초안 함수가 아직 배포되지 않은 경우에만:
  firebase deploy --only "functions:ai:generateLaunchAiDraft" --project orqube-576e7
이 함수는 기존 OPENAI_API_KEY 설정이 필요합니다.
전체 Functions나 Firestore Rules를 이번 안내만으로 일괄 배포할 필요는 없습니다.
