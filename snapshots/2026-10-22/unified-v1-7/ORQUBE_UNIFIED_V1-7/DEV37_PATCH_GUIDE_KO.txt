ORQUBE DEV37 수정 패치

적용: ZIP 내부 lib, web, functions_ai 폴더를 DEV37 프로젝트 루트의 같은 폴더에 덮어쓰세요. 전체본이 아니라 변경 파일과 필요한 서버·음향 파일입니다.

수정:
- 3자토론 요청에서 누락된 comedy 설정 전달.
- 서버 comedyApplied 응답을 확인한 뒤만 풍자 적용 표시. 미배포 서버는 명확한 오류 안내.
- 사용자 클릭 시 Web Audio 재생 권한 확보, 효과음 버퍼 재사용 및 정지 처리.
- 첫 홈 상단 및 하단의 AI 토론 / 혼합 토론 버튼 제거. 기존 토론 페이지와 내부 기능 보존.

프로젝트 루트에서:
flutter pub get
firebase deploy --only functions:ai:generateThreeWayDebate,functions:ai:generateMixedDebate
flutter run -d chrome

위 functions 명령은 원격 AI 서버 함수를 갱신합니다. 공개용 Hosting 화면은 배포하지 않습니다.
로컬 실행만으로 서버 함수는 갱신되지 않습니다. 환경 설정·API 키는 기존 값을 유지하세요.
공개용 Hosting 배포 명령은 포함하지 않았습니다.

확인:
내부 대시보드에서 3자토론 열기 → 풍자 모드 ON → 주제 입력 → 시작.
서버 패치 누락 메시지가 나오면 함수 배포 결과 확인.
웃음/박수 미리듣기 및 음량 확인. 음소거 상태에서는 효과음도 들리지 않습니다.
풍자 내용의 재미는 생성 결과마다 차이가 있으므로 실제 재생으로 확인해야 합니다.
첫 화면에서 토론 버튼이 사라졌는지 확인.

검증: 기존 Node 테스트 35개 및 Web Audio 신규 테스트 1개 통과. JS 구문 검사 통과.
Flutter SDK 부재로 Flutter 빌드, 실제 Firebase 서버 호출, 브라우저 음향 실기기 검증 미실시.
