ORQUBE DEV34 · 사람 + AI 토론방 BETA 적용 안내

1. 적용
압축 안의 lib, functions_ai, firestore.rules를 기존 ORQUBE_DEV34 프로젝트 루트에 덮어쓰세요.
프로젝트 루트는 pubspec.yaml과 firebase.json이 있는 폴더입니다.
이 ZIP은 변경된 파일만 담은 패치입니다. 기존 프로젝트에서 실행해야 합니다.
기존 AI 3자 토론의 화면·인물·편집 관점·녹화 기능은 보존했습니다.
홈 상단 서비스와 하단 링크에 별도 '사람 + AI 토론방' 메뉴를 추가했습니다.

2. 개발용 서버 적용 (공개 홈페이지 Hosting은 배포하지 않음)
프로젝트 루트 PowerShell/터미널:

flutter pub get
firebase deploy --only functions:ai:manageMixedDebateRoom,functions:ai:generateMixedDebate,functions:ai:generateMixedDebatePortrait,functions:ai:generateDebateSpeech,firestore:rules --project orqube-576e7
flutter run -d chrome

현재 프로젝트의 Firebase Functions ai 코드베이스와 Firestore Rules를 사용합니다.
이 명령은 Hosting을 배포하지 않으므로 공개 홈페이지 화면은 바뀌지 않습니다.
단, 같은 Firebase 프로젝트를 쓰므로 서버 함수·Rules는 해당 프로젝트에 적용됩니다.
기존 OPENAI_API_KEY 및 DEBATE_ENABLED=true 설정을 그대로 사용합니다.
이미지 모델 기본값: gpt-image-1 (OPENAI_DEBATE_IMAGE_MODEL로 변경 가능).
이미지 모델 사용 권한·크레딧이 필요합니다. AI 이미지 생성 버튼을 눌렀을 때만 이미지 요청이 발생합니다.
기존 API 키를 Flutter 소스나 웹 파일에 넣지 마세요.

3. 사용 순서
ORQUBE 로그인 및 이메일 인증 → 사람 + AI 토론방 → 방 이름·주제·전체 시간·공개 범위 → 방 만들기.
각 인물 카드의 '프로필 설정'에서 진행자·패널 3명의 사람/AI, 별칭, 남성/여성 음성을 선택합니다.
인물 묘사: 나이대, 외모, 머리·수염, 옷차림, 표정 등을 자유롭게 입력.
직접 사진을 선택하거나 '묘사로 AI 이미지 생성'을 선택해 생성 버튼을 누르고 저장합니다.
성격·언변·관점/이념은 별도 입력란이며 AI 발언 생성에 적용합니다.
외모 묘사는 발언 프롬프트에 전달하지 않습니다.
사진은 JPG로 축소·압축한 뒤 방 설정에 저장합니다. 인물당 150KB 이하입니다.
설정은 시작 전에 저장합니다. 진행 중에는 변경하지 않습니다.

4. 사람 참가자와 여러 토론방
'초대 링크 복사'로 링크를 전달합니다. 받는 사람도 ORQUBE 로그인·이메일 인증 후 입장합니다.
공개방은 로그인 회원이 방 목록이나 코드로 입장할 수 있습니다.
비공개방은 유효한 초대 링크가 있어야 첫 입장이 가능합니다. 이미 입장한 회원은 내 방 목록에서 재입장합니다.
방장은 참가자가 입장한 후 인물 설정에서 '사람'을 선택하고 해당 참가자를 지정합니다.
사람은 한 좌석만 맡을 수 있습니다. 방장도 직접 사람 진행자/패널로 지정할 수 있습니다.
사람 참가자는 글을 입력해 발언합니다. AI는 사람의 발언을 대신 만들지 않습니다.
등록한 글은 자막에 표시하고, 음성이 켜져 있으면 선택한 합성 음성으로 읽습니다.
실제 사람의 마이크 통화·영상 통화는 이번 패치에 포함하지 않습니다.
방장은 설정·시작·종료를 관리합니다. 사람 좌석은 발언·시민 질문, 관람자는 시민 질문을 등록할 수 있습니다.
방별 설정·발언·질문·최종 요약·녹화 파일명 기록은 서로 다른 방 문서에 저장됩니다.
현재 목록에는 내 방 최대 50개와 공개방 최대 50개가 표시됩니다.
여러 방을 동시에 진행할 수 있으며 각 방의 방장 화면을 열어 두어야 자동 AI 진행이 이어집니다.
방장 탭을 닫거나 기기가 절전되면 자동 진행이 멈출 수 있습니다. 재입장하면 서버에 저장된 종료 시간을 기준으로 복구합니다.

5. 토론·음성·녹화
방장 '토론 시작' → AI 반박·재반박, 사람 입력 발언 및 시민 질문이 같은 기록에 표시됩니다.
관람 화면에서는 '음성 활성화'를 눌러 브라우저 오디오 재생을 허용하세요.
음량 슬라이더·음소거·음성 켜기/끄기·자막 켜기/끄기가 있습니다.
전체 시간이 끝나면 방장 화면에서 최종 요약을 생성하며 진행자 좌석에 선택한 합성 음성으로 읽습니다.
'종료·최종 음성 요약' 버튼으로 일찍 종료할 수도 있습니다.
최종 요약은 실제로 게시된 최근 최대 1000개 발언에 근거하며 대기 중인 AI 발언은 포함하지 않습니다.
외부 사실 검증이나 최신 뉴스 검색이 자동 수행되는 기능은 아닙니다.

녹화: PC Chrome/Edge → '녹화 시작' → 현재 토론 탭 선택 → '탭 오디오 공유' 체크.
'녹화 종료·저장'을 누르면 WEBM 또는 브라우저 지원 형식으로 기기에 다운로드됩니다.
기존 3자 토론과 같은 녹화 모듈을 사용하며 마이크를 요청하지 않습니다.
탭 소리를 선택하지 않으면 영상만 저장됩니다.
방장 화면에서 정상 종료·저장한 녹화는 방별 파일명·저장 시간 기록을 남깁니다.
영상 원본은 자동 서버 업로드하지 않습니다. 기기에 받은 파일을 보관하세요.
브라우저 자체 공유 중지 버튼으로 종료하면 다운로드는 되지만 방별 파일 기록은 남지 않을 수 있습니다.
모바일 브라우저에서는 녹화 지원이 제한될 수 있습니다.

6. 확인 순서
- 기존 AI 3자 토론을 열어 기존 기능 유지 확인.
- 새 공개방 생성 → 네 인물 설정 → 한 패널을 여성 음성으로 설정.
- 비공개방 생성 → 다른 로그인 계정에서 초대 링크로 입장.
- 사람 패널 지정 → 직접 발언 → AI의 후속 반박 확인.
- 관람자 직접 발언 제한 및 시민 질문 등록 확인.
- 1분 토론 → 자동 최종 음성 요약.
- 탭 오디오 포함 녹화 → 저장 파일에서 토론 음성 확인.
- 방 목록 재입장 → 기록·요약·프로필 복원 확인.

7. 검증 범위
서버 구문 검사 및 기존/신규 서버 테스트 31개가 통과했습니다. Dart 포맷 검사로 새 코드의 구문을 확인했습니다.
Flutter 실행 검사는 자동 승인 검토에서 클라우드 메타데이터 접근 위험으로 차단되어 빌드를 완료하지 못했습니다.
권한·초대·중복 요청·사람 발언 보호·성격 설정 전달·외모/발언 분리 등을 모의 서버로 확인했습니다.
실제 Firebase 배포, 유료 AI 이미지/음성 요청, 다른 기기 동시 참가·실제 녹화는 사용자 환경에서 위 순서로 확인해야 합니다.
이 패치를 자동으로 배포하지 않았습니다.
