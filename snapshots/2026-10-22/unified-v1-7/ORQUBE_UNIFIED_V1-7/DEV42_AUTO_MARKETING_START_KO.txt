[이 버전의 정확한 범위]
외부 SNS 계정 연결, 외부 자동 게시, 자동 DM, 자동 가입, 자동 광고 집행은 포함하지 않습니다.
유튜브는 영상 대본 초안이며 영상 파일 생성·업로드가 아닙니다.
게시 반응은 관리자 수기 기록입니다. 방문·가입·Pi 연결 자동 추적은 아직 연결하지 않았습니다.
웹 검색 결과와 AI 해석이 실제 허용을 보장하지 않습니다. 원문 링크를 눌러 확인하세요.
출처 목록에 후보 URL과 활동 근거 URL이 없으면 후보를 저장하지 않습니다. 규칙 출처가 없으면 미확인입니다.
자동 검색은 회원 전용 게시판에 로그인하거나 내부 정보를 읽지 않습니다. 일부 후보와 국가가 검색에서 누락될 수 있습니다.
기존 코드에 자동 발굴을 추가한 것이며, 채널별 자동 게시까지 완성한 버전은 아닙니다.

기존 OPENAI_API_KEY를 재사용합니다. 이미 등록되어 있으면 다시 등록하지 마세요.

[처음 테스트]
1. 이메일 인증된 기존 관리자 계정으로 로그인합니다.
2. AI MARKETING → 외부 커뮤니티 자동 발굴 · 지속 마케팅에 들어갑니다.
3. 처음에는 분야 1개와 국가 1개만 선택하고, 확인된 기능·소개 페이지 주소를 입력합니다.
4. 자동 발굴은 끈 채 설정 저장 → 지금 1회 발굴을 누릅니다.
5. 검색은 수 분 걸릴 수 있습니다. 응답이 끊기면 재시도 전에 새로고침으로 실행 기록을 확인하세요.
6. 원문 근거·실제 활동·홍보 규칙을 확인하고 채택 또는 보류합니다.
7. 조건부 허용이면 필요한 운영자 승인을 별도로 받아야 합니다. 초안 사용 승인 버튼은 외부 게시를 하지 않습니다.
8. 자동 운영을 원하면 자동 발굴을 켜고 간격·한도를 정한 뒤 설정 저장을 누릅니다.
9. 화면을 닫아도 서버가 매시간 설정을 확인합니다. 설정한 시간 간격이 지난 첫 확인 시각에 실행됩니다.
10. 중지하려면 자동 발굴을 끄고 저장합니다. 이미 실행 중인 1회 작업은 끝날 수 있습니다.

[기본값과 사용량]
초기 자동 발굴 OFF / 6시간 간격 / 하루 검색 실행 4회 / 한국시간 자정 기준 초기화.
수동 '지금 1회 발굴'도 한도에 포함하며 실패한 시도도 1회로 계산합니다.
수동 실행은 간격을 기다리지 않지만, 동시 실행 차단과 하루 한도는 유지합니다.
하루 1~12회, 간격 1~24시간 중 선택할 수 있습니다.
1회에 웹 검색 응답 1회(웹 도구 최대 2회), 후보 추출 1회, 조건이 맞으면 캠페인 생성 최대 1회가 호출됩니다.
API 비용과 Firebase 비용이 발생합니다. 횟수 제한은 금액 상한이 아닙니다. 모델은 gpt-4.1-mini 기본값입니다.
같은 후보·국가·분야의 초안은 한국시간 같은 날짜에 중복 생성하지 않습니다.
기본 5분야×5국가=25개 조합을 1회 1조합씩 돌므로 하루 4회일 때 전체 1순환은 약 7일입니다.
국가를 늘리면 1순환 시간이 늘어납니다. 모든 국가를 매번 동시에 검색하는 구조가 아닙니다.
자동 실행이 꺼져도 배포된 Scheduler가 매시간 상태를 확인하므로 소액 인프라 비용은 발생할 수 있습니다.
현재 화면은 최근 후보 40개·초안 30개·실행 15개까지 표시하며 과거 기록은 서버에 남습니다.
새 후보 생성·재조사 기능이며 무기한 실시간 감시가 아닙니다.

[승인과 재확인]
검색 결과의 AI 규칙 판정은 관리자 확인과 별개입니다.
규칙 근거가 바뀌거나 마지막 검토 후 14일이 지나면 재확인이 필요합니다.
이미 승인한 초안도 후보 검토가 유효하지 않으면 목록에서 보류로 표시합니다.
제외한 후보는 재검색되어도 제외 상태를 유지하며, 초안 생성 대상에서 빠집니다.
운영자가 적은 기능 사실과 성과 메모 역시 실제 확인한 내용만 사용하세요.
