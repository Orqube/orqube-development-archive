# ORQUBE 기간형 스테이킹 개발본

승인된 조건: 3개월 연 4%, 6개월 연 6%, 9개월 연 7%, 12개월 연 8%.
보상은 단리이며 실제 잠금 초 / (365일의 초)로 계산하고 토큰 최소 단위에서 버림합니다.
UTC 달력 개월을 사용하며 월말은 해당 월 마지막 날로 맞춥니다. 윤년에도 분모는 365일입니다.

ORBS 메인넷 주소: `0xe3998db5a59d650951faf264a67618b1eb4a307b` (사용자 제공).
전체 공급량 기준: 310,000,000 ORBS. 이 숫자가 스테이킹 보상 예산은 아닙니다.
보상 예산 100만 ORBS는 논의된 제안일 뿐, 확정되거나 충전된 금액이 아닙니다.

## 현재 상태

- 앱 화면: 네 가지 기간과 고정 이율 적용, 모의 예치 및 모의 출금.
- 컨트랙트: 소스·ABI·배포 바이트코드·테스트 소스 제공. 미배포·미감사.
- 앱의 실제 지갑 승인·예치·출금 연결은 아직 구현되지 않았습니다.
- 실제 토큰 ABI/소스·decimals·전송 동작·공급량은 별도로 온체인 확인해야 합니다.
- 앱의 모의 기록은 화면을 닫으면 초기화됩니다. 실제 자산이나 채굴 잔액을 변경하지 않습니다.

## 컨트랙트 동작

운영자는 ORBS 토큰에서 스테이킹 주소에 필요한 금액만 approve한 뒤 fundRewards(amount)를 호출합니다.
이용자도 토큰 approve 후 stake(amount, months)를 호출합니다. amount는 decimals에 맞춘 정수입니다.
새 예치 전 잔액에서 기존 원금과 예약 보상을 뺀 가용 보상 재원을 확인합니다.
재원이 모자라면 새 예치를 거부하며 이용자 원금을 보상 재원으로 사용하지 않습니다.
예치별 보상과 만기를 저장합니다. 본 버전에는 이율 변경 기능이 없습니다.
만기 이후 이용자 본인이 withdraw(id)로 원금과 보상을 함께 받습니다. 중도 출금·중복 출금을 막습니다.
운영자가 신규 예치를 일시 정지해도 만기 출금은 가능합니다.
운영자 원금 인출 기능과 보상 잔여금 회수 기능은 없습니다. 충전 전 필요한 금액을 확인하세요.
전송 수수료·리베이스 토큰은 지원하지 않습니다. 재진입 방어와 토큰 전송 반환값 확인을 포함합니다.

## 배포와 연결 순서

1. 테스트넷에는 MockToken 등 테스트 토큰을 배포합니다. 메인넷 ORBS 주소를 테스트넷에서 사용하지 않습니다.
2. Foundry 설치 환경에서 `forge test -vv`를 실행해 테스트넷 검증 전 테스트를 통과시킵니다.
3. 실제 ORBS의 전송 방식·관리 권한·decimals 등을 확인하고 독립적인 보안 검토를 받습니다.
4. 배포 시 constructor(tokenAddress, initialOwner)에 해당 네트워크의 토큰 주소와 운영자 주소를 넣습니다.
5. 배포 후 생성되는 스테이킹 주소를 network-config.json에 기록하고 ABI와 함께 앱 지갑 연결을 개발합니다.
6. 운영자가 승인한 보상 예산을 충전하고 소액 예치·만기 출금 검증 후 서비스를 시작합니다.

복구문구·개인키를 코드, 문서 또는 채팅에 입력하지 않습니다. 지갑에서 직접 서명합니다.
현재 압축본만 실행해도 메인넷에 배포되거나 자금이 이동하지 않습니다.

## 검증 결과

Solidity 0.8.30, optimizer 200회, EVM paris로 컨트랙트 및 테스트 소스 컴파일 성공.
`node scripts/compile.cjs`로 ABI·바이트코드를 재생성할 수 있습니다 (functions_ai의 기존 solc 사용).
테스트 소스: 4개 기간·보상 예약, 재원 부족, 잘못된 기간, 만기 직전 거부, 만기 출금,
중복 출금, 관리자 제한, 정지 중 만기 출금, 월말·윤년.
이 작업 환경에는 Foundry와 Flutter SDK가 없어 테스트 실행과 Flutter 빌드는 수행하지 못했습니다.
컴파일 성공은 보안 감사나 실제 체인 검증을 의미하지 않습니다.
