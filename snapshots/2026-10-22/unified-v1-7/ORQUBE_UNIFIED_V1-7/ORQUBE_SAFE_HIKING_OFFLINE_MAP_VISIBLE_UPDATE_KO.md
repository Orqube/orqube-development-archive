# ORQUBE 안전산행 오프라인 지도 버튼 가시성 보강

기준본: ORQUBE_GUIDE_6LANG_OFFLINE_2026-08-13

- 기존 기능·디자인·라우팅 유지
- 안전산행 상단에 `오프라인 지도 저장` 준비 카드를 추가하여 화면을 많이 내리지 않아도 바로 찾을 수 있도록 개선
- 저장 전에는 `산행 전 저장 필요`, 저장 후에는 `지도 저장됨 · 저장시각` 표시
- 모바일 앱에서는 현재 보이는 지도 범위를 기기에 저장하는 기존 실제 저장 로직과 연결
- 인터넷 단절 시 저장 지도 위에 현재 GPS, 청록색 이동경로, 출발점을 계속 표시하는 기존 로직 유지
- Chrome/Web에서는 실제 저장이 모바일 앱 전용임을 화면에서 명확히 안내
- 새 안내 문구를 한국어/영어/일본어/중국어/프랑스어/포르투갈어 6개국어 카탈로그에 추가

모바일 확인 순서:
1. 안전산행 화면 진입
2. 인터넷 연결 상태에서 필요한 산행 구간으로 지도 이동/확대
3. 상단 `오프라인 지도 저장` 누르기
4. `지도 저장됨` 상태 확인
5. 모바일 데이터/Wi-Fi를 끈 뒤 저장 지도, GPS, 청록색 경로, 출발점 표시 확인
