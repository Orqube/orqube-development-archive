개발용 영상 게시판 추가 안내

이 ZIP은 마지막 혼합 토론방 + 풍자·효과음 + 개발용 영상 게시판을 모두 포함합니다.
기존 프로젝트 루트(pubspec.yaml이 있는 폴더)에 압축 내용을 덮어쓰세요.
앞서 통합 패치를 적용했어도 이 ZIP으로 다시 덮어쓰면 됩니다.

개발용 첫 홈 화면 하단에 영상 게시판이 표시됩니다.
ORQUBE 소개 영상은 기존 YouTube 링크로 연결됩니다.
토론 영상은 실제 업로드 주소를 아직 받지 않아 '업로드 준비 중'으로 표시됩니다.
lib/orqube_public_content_config.dart 파일의
static const String debateVideoUrl = '';
빈 따옴표 안에 YouTube 공유 주소를 넣고 다시 실행하세요.
예: https://youtu.be/실제영상ID
게시물을 누르면 YouTube로 이동합니다. 로그인 없이 열람 가능합니다.

로컬 테스트:
flutter pub get
flutter run -d chrome

전체 Flutter 빌드는 이 작업 환경에서 수행하지 못했습니다.
공개용 Hosting 배포는 수행하지 않았습니다.
풍자/혼합 토론방 서버 적용은 ORQUBE_DEV34_COMEDY_GUIDE_KO.txt를 참고하세요.
