# ORQUBE AI 3-WAY DEBATE BETA

## 적용 범위

- 개발용 전체본에만 신규 화면과 진입 버튼을 추가했습니다.
- 공개용 프로젝트 및 공개 배포 설정은 수정하지 않았습니다.
- 홈의 전체 서비스 영역과 하단 ORQUBE LINKS에서 진입할 수 있습니다.

## BETA 구조

- 실존 인물과 무관한 A·B·C 가상 패널
- A: 실행·혁신, B: 권리·위험, C: 중립·근거 관점
- 1~10분 시간제 토론, 발언 순서 및 남은 시간 표시
- 입론 → 반박 → 근거 확인 → 재반박 → 중간/최종 중립 요약
- 패널별 음성 속도·피치 분리, 실시간 자막 ON/OFF
- 시민 질문 삽입 및 최종 미해결 쟁점 반영 구조
- 외부 출처 미연결 문장은 검증 완료로 표시하지 않는 안전 장치
- 실존 인물 얼굴·음성 모방 금지 고정 안내

## 현재 BETA 제한

- 토론 문장은 화면 흐름 검증을 위한 로컬 시연 스크립트입니다.
- 웹 Chrome 계열 브라우저에서는 기기 Web Speech 음성을 사용합니다.
- Android/iOS 네이티브 음성 및 생성형 AI·검색 기반 근거 검증은 다음 서버 연동 단계입니다.
- 정치·선거 주제는 출처, 날짜, 관할 법규, 광고/여론조사 규정을 추가 검토한 후 공개해야 합니다.

## 확인 순서

1. `flutter pub get`
2. `flutter run -d chrome`
3. 첫 화면의 `AI DEBATE · BETA` 선택
4. 주제와 1~10분 시간을 설정하고 토론 시작
5. A/B/C 음성·자막·반박·재반박·시민 질문·최종 요약 확인
