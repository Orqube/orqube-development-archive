# ORQUBE 안전산행 FINAL OFFLINE

기준 원본: `ORQUBE_SAFE_HIKING_STAGE2_2026-08-12.zip`

## 최종 목표

산행 전 지도 저장 → 인터넷 완전 단절 → 저장 지도 + 현재 GPS + 청록색 이동경로 + 출발점 → 인터넷 복구 → 보호자 공유 재개 → 안전하산 종료

## 이번 FINAL에서 추가·확정된 기능

1. **모바일 앱 전용 오프라인 지도 저장**
   - 안전산행 지도에서 사용자가 현재 보고 있는 산행 예정 범위의 **배경지도만** PNG로 저장합니다.
   - 저장 당시의 GPS 마커·청록색 이동경로는 이미지에 굳히지 않고, 배경지도와 위·아래·좌·우 좌표 경계를 함께 기기에 보관합니다.
   - 앱을 다시 실행해도 저장 지도를 다시 읽을 수 있도록 Application Support 영역에 저장합니다.
   - 같은 파일명을 덮어쓰지 않고 새 저장본으로 교체하여 이전 이미지 캐시가 남는 문제를 방지합니다.

2. **인터넷 두절 시 저장 지도 표시**
   - 안전산행에서는 저장 지도를 지도 레이어 위에 지리 좌표에 맞춰 표시합니다.
   - 온라인 타일 요청이 실패해도 저장된 범위에서는 저장 지도가 그대로 남습니다.
   - 그 위에 기존 현재 GPS, 청록색 GPS 이동경로, 출발점 마커가 계속 갱신됩니다.

3. **지도에서 바로 저장**
   - 안전산행 지도 우측에 `현재 지도 저장` 버튼을 추가했습니다.
   - 오프라인 안전 정보 카드에도 같은 저장 버튼과 저장 시각, 삭제 버튼을 추가했습니다.
   - 저장 시 지도는 북쪽이 위가 되도록 자동 정렬한 뒤 좌표 경계와 함께 저장합니다.

4. **기존 2차 기능 유지**
   - 보호자 이름/연락처
   - 귀환 예정시간
   - 산행 종료까지 위치 공유
   - GPS 이동 경로 및 출발점
   - 오프라인 좌표/고도/GPS 오차/기록거리/출발점 방향
   - 안전정보 복사
   - `안전하게 하산했습니다`
   - 인터넷 복구 후 Firestore 위치 공유/기록 전송 재개 흐름

5. **웹 보호**
   - 웹에서는 기존 OpenStreetMap 지도를 그대로 사용합니다.
   - 파일 저장 구현은 조건부 import로 모바일/데스크톱 IO 환경에만 연결되어 웹 코드에 `dart:io`가 들어가지 않습니다.
   - 웹에서 저장 버튼을 누르면 모바일 앱 전용 기능이라는 안내만 표시하며 기존 웹 지도 동작은 유지합니다.

6. **6개국어 문구**
   - 한국어/영어/일본어/중국어/프랑스어/포르투갈어에 오프라인 지도 저장 관련 문구를 추가했습니다.

## 사용법

1. ORQUBE 앱에서 `안전산행`으로 들어갑니다.
2. 위치 서비스를 켜고 현재 위치를 확인합니다.
3. 보호자와 귀환 예정시간을 설정합니다.
4. **산행 예정 경로 전체가 한 화면 안에 들어오도록 지도를 이동하고 확대/축소합니다.**
5. 지도 우측의 다운로드 아이콘 또는 오프라인 안전 정보 카드의 `현재 지도 저장`을 누릅니다.
6. 카드의 `저장 지도`에 저장 시각이 표시되는지 확인합니다.
7. `산행 시작`을 누릅니다.
8. 모바일 데이터/Wi-Fi가 끊겨도 위치 서비스(GPS)는 켜 둡니다.
9. 저장 지도 위에서 현재 GPS, 청록색 이동경로, 출발점을 확인하며 이동합니다.
10. 통신이 복구되면 앱이 계속 실행 중이고 Firestore 오프라인 쓰기 큐가 유지되는 범위에서 진행 중인 위치 공유/기록 전송이 재개됩니다.
11. 하산 후 `안전하게 하산했습니다`를 눌러 공유와 GPS 산행 세션을 종료합니다.

## 매우 중요한 사용 원칙

- FINAL의 `현재 지도 저장`은 **사용자가 실제로 보고 있는 한 화면 범위**를 저장합니다.
- 장거리 산행은 저장 전에 지도를 충분히 축소하여 예정 산행 구간과 우회·귀환 범위까지 한 화면에 포함시키는 것이 좋습니다.
- 저장 범위 밖으로 나가면 인터넷이 없는 상태에서는 배경 지도가 보이지 않을 수 있으므로, 청록색 이동경로·출발점·좌표/방향 정보도 함께 사용합니다.
- 휴대폰 위치 서비스/GPS 자체가 꺼져 있으면 인터넷 유무와 관계없이 현재 위치를 기록할 수 없습니다.
- 이 기능은 구조기관용 전문 산악 내비게이션을 대체하지 않으며, 종이지도·보조배터리·통신수단 등 기존 안전수단과 함께 사용하는 것이 좋습니다.
