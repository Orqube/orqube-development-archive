# ORQUBE 안전산행 2차 작업본

기준 원본: 사용자가 제공한 `orqube-app-hiking2.zip` 1차 안정본

## 보호 원칙
- 1차 안정본 ZIP은 수정하지 않음.
- 기존 에어소프트/안심귀가/안전산행 GPS·오프라인 경로·SOS·라우팅은 유지.
- `pubspec.yaml`, `firestore.rules`, 라우팅 파일은 변경하지 않음.
- 기존 의존성 `share_plus`를 사용하므로 새 패키지 추가 없음.

## 이번 2차 추가 기능
1. 보호자 설정
   - 보호자 이름/연락처 입력
   - `users/{uid}.safeHikingGuardian`에 저장 시도
   - 네트워크 실패 시 현재 화면 상태는 유지하여 GPS 산행 기능을 막지 않음

2. 귀환 예정시간
   - 날짜/시간 선택
   - 진행 중인 안전산행 세션의 `plannedReturnAt`에 반영
   - 미설정 상태로 산행을 시작하면 기존 방식과 동일하게 4시간 뒤를 기본 귀환 예정시간으로 사용

3. 산행 종료까지 위치 공유
   - 안전산행 모드에서는 기존 30분 제한 대신 사용자가 종료할 때까지 공유 상태 유지
   - GPS 스트림이 활성화된 동안 `airsoft_live_locations/{uid}`를 계속 갱신
   - 인터넷 단절 시 기기 GPS 경로 기록은 계속 유지되며 원격 전송은 통신 복구 시점까지 지연될 수 있음
   - 에어소프트/안심귀가의 기존 30분 공유 동작은 그대로 유지

4. 안전하게 하산했습니다
   - 안전 하산 확인 후 `hiking_sessions/{uid}`에 `safeDescent: true`, `status: safe_completed` 기록 시도
   - 위치 공유와 GPS 세션을 함께 종료
   - 보호자에게 전달할 현재 위치 포함 완료 메시지를 시스템 공유창으로 전달

## 수정 파일
- `lib/pages/airsoft_map_page.dart`
- `lib/utils/orqube_i18n.dart` (신규 기능 문구 6개국어 대응)
- 본 설명서 파일만 추가

## 실행 확인 권장 순서
1. 안전산행 진입
2. 보호자 설정
3. 귀환 예정시간 설정
4. 산행 시작
5. 산행 종료까지 위치 공유 시작
6. GPS 이동 경로/출발점 정보가 기존대로 갱신되는지 확인
7. 인터넷을 잠시 끊어 GPS 경로가 계속 기록되는지 확인
8. 다시 연결 후 위치 공유가 계속 갱신되는지 확인
9. `안전하게 하산했습니다` 실행
10. 위치 공유 종료, 산행 세션 종료, 완료 공유창 표시 확인

## 주의
현재 Firestore 보안 규칙은 기존과 동일하게 실시간 위치 문서를 소유자와 관리자만 읽도록 유지했습니다. 보호자에게는 시작/종료 시 시스템 공유창으로 현재 위치 메시지를 전달합니다. 보호자가 ORQUBE 안에서 실시간 지도를 직접 보는 전용 화면/권한은 다음 단계에서 별도로 설계하는 것이 안전합니다.
