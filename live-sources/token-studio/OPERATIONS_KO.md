## 실서비스 확인이 남은 부분

본인 계정 로그인 후 실제 Firestore 목록·QR 원본 읽기 성공 여부와 실제 지갑 거래는 확인하지 않았다. 테스트용 계정이나 사용자 인증 자료를 임의로 만들지 않았다.

모바일 Kaia 앱 간 API 연결은 현재 스테이킹의 메인넷 경로를 복사하지 않았으며, Kairos 지원 확인·서버 연결이 남았다. 현재 일반 모바일 브라우저는 지갑 내장 브라우저 진입 안내를 제공한다.

전송 결과는 이 브라우저에서 관찰한 기록이며 서버 확정 상태가 아니다. launch_projects의 검증 완료 필드를 클라이언트에서 변경하지 않는다. 다중 기기 전송 잠금·서버 receipt 검증·통합본 완료 상태 갱신은 Firebase 서버 작업이 필요하다. 다른 기기의 미확인 거래가 없음을 확인한 뒤 1회만 테스트한다.

210업종 전체 목록·전문 생성 상세 편집기는 이번 이어하기 연결에 새로 만들지 않았다. 기존 프로젝트의 타입이 없는 경우 추정 분류하지 않는다. 로컬 신규 생성 폼은 기존 밈코인 간편 생성 범위이며, 모든 유형을 대신하는 편집기가 아니다.
