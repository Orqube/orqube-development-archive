# ORQUBE 통합 개발 22차 — 공식 기술 개발 기록

**ORQUBE Foundation | 2026년 11월 17일**

## 우리가 추진하는 개발

우리는 독립 프로그래밍 언어 OQL을 기반으로 독립 블록체인과 채굴, 사슴지갑, 토큰·NFT, 탈중앙화 거래, 스테이블코인 기반 기술, 체인 탐색기를 유기적으로 연결하는 연구개발을 진행하고 있습니다.

22차 개발에서는 기존 21차까지의 소스를 유지하면서 OQL의 실행 기능과 각 서비스의 기초 검증 로직을 확장했습니다.

## OQL 언어 개발

우리는 제한된 Rust 기반 OQL 컴파일러와 가상머신에 **변수 단항 음수 연산**을 추가했습니다. 예를 들어 `let a = 42`, `let negative = -a`와 같은 계산식을 처리하도록 소스를 작성했습니다. 또한 가상머신에서 변수를 스택으로 읽어올 때 크기 제한을 검사하도록 보완했습니다.

## 22차 통합 개발 현황

- **독립 블록체인:** 거래 수수료 차감과 송금의 메모리 내 상태 계산
- **채굴:** 반감 보상 및 발행 상한 검사
- **사슴지갑:** 논스·잔액·수수료 사전검사
- **토큰·밈코인:** 중복 수신자와 배분량 검증
- **210개 직업군 토큰:** 코드 및 토큰 심볼 검증
- **NFT:** 소유권 변경의 사전검사
- **DEX:** 교환 예상량과 최소 수령량 계산
- **스테이블코인:** 입력된 준비금 수치와 상환 가능량 대조
- **체인 탐색기:** 연속 블록 높이 데이터의 페이지 처리

위 항목들은 **Rust 기반 소스 수준의 참조 구현**입니다. 실제 메인넷 합의, 채굴, 사슴지갑 Build 22 연동, 토큰·NFT 발행, 실거래, 준비금 독립 검증 또는 운영 탐색기가 완료되었다는 의미는 아닙니다.

우리는 관련 테스트 코드도 작성했으나, 현재 개발 환경에서는 Rust 컴파일과 자동 테스트 실행 결과를 확인하지 못했습니다. 실제 검증이 완료될 때까지 이 단계의 기능을 상용화 또는 검증 완료로 표현하지 않겠습니다.

## 다음 개발 방향

우리는 OQL의 문법·실행 기능을 지속적으로 확장하는 동시에, 작성한 소스의 컴파일·테스트·보안 검증을 강화하고 실제 체인과 서비스의 연결을 단계적으로 추진하겠습니다.

핵심 구현 소스는 비공개 저장소에 보존하고, 공개 가능한 기술 개발 현황과 검증 결과는 ORQUBE 명의로 공개하겠습니다.
