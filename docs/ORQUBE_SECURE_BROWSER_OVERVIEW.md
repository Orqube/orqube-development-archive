# ORQUBE Secure Browser — Public Overview

Status: Concept and planning (not yet implemented)
Date: 2026-11-05

## Vision
One browser, connected ORQUBE services, and a safer open internet. ORQUBE Secure Browser is proposed as a free consumer browser and an entry point to a future paid website-security service for organizations.

## Hybrid experience
- Simple start page with a search/address bar and customizable quick links.
- Optional portal panel for news, sports, search and community content.
- Unrestricted access to ordinary websites and user-selected search engines.
- Standard browsing essentials: tabs, bookmarks, history, downloads and accessibility.
- User-controlled shortcuts, with no requirement to use ORQUBE services.

## ORQUBE services
Provide convenient links to Ullim SNS, Ullim Wordpad, ORQUBE portal, airsoft, mining, staking, independent-chain explorer and safe-companion services where available. Existing sites remain independently accessible. Single sign-on requires separate secure design; a shortcut does not imply account integration.

## Security principles
- Phishing and malicious-site warnings, tracker controls and clear permissions.
- Favor on-device checks, minimal data collection, timely engine updates and independent security testing.
- Warn proportionately; provide understandable reasons and false-positive review.
- Explore signed website-integrity attestations and blockchain-backed audit evidence, without claiming that blockchain alone prevents malware.
- Research standards-based post-quantum cryptography only where supported and verified.
- Do not promise absolute security.

## Delivery roadmap (proposed)
1. Validate user needs and build a minimal browser/security extension prototype.
2. Develop an Android browser using a maintained web engine, with core navigation and ORQUBE shortcuts.
3. Integrate optional document workflow and portal experience.
4. Evaluate advanced threat detection and verifiable integrity records.
5. Pilot a separately priced website-security dashboard for operators.

## Business model
Free consumer access; optional paid services for website operators and enterprises. Avoid monetizing private browsing history.

## Boundaries
This is a public product-direction document, not a deployed browser, completed security assessment, or disclosure of private security architecture. Internal threat models, implementation details, credentials and security-sensitive research belong in a restricted repository.
