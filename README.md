## Documentation and Verification Standards

We distinguish historical development dates from actual publication dates. Requests and plans, available source, tests, and verified deployments are tracked separately. Labels such as FINAL or FIXED in filenames are not treated as evidence of successful verification. This archival update did not execute existing source or modify production services.

Published source files are archival copies with asset and operational configuration exclusions. Review [Publication Scope and Exclusions](PUBLICATION_SCOPE.md) first. Not all historical versions or current per-site source repositories have been recovered.
