## 기록 기준

과거 작업일과 실제 등록일을 구분합니다. 요청·계획, 소스 확보, 테스트 및 배포 확인을 구분하며 파일명의 FINAL/FIXED 표기를 검증 결과로 간주하지 않습니다. 이번에는 기존 소스를 실행하거나 운영 서비스를 변경하지 않았습니다.

등록된 소스는 자산·운영 설정을 제외한 보관본입니다. [공개 등록 범위와 제외 목록](PUBLICATION_SCOPE.md)을 먼저 확인하세요. 전체 과거 버전과 현재 사이트별 소스가 모두 확보된 것은 아닙니다.
